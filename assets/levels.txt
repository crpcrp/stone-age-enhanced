# Levels of the free asset set, with their passwords. Each level is a header
# line and 11 rows of 20 tiles. With the original's files the game plays the
# original's levels instead.
#   time        countdown parameter, 0..999 (shown value is time + time/4)
#   theme       tile set 0..4 (tiles_1..5.bmp)
#   palette     tint of the status bar and the player, 0..5
#   background  0..4 (background_a1..5 or background_b1..5)
#   flag        fourth header byte; the game reads it but does not use it
#   password    six letters, a consonant and a vowel in turn; consonants are
#               D M T S P F B R N L V W H K C, vowels U I A O E
#
# Tile codes. The picture of each tile is in tiles_1..5.bmp, eight per row,
# in this order: A B C D E F G H / I J K L M N O P / Q R S ...
#   A  empty space: no floor to walk on; platforms travel across it
#   B  floor
#   C D E F  platform that moves up / down / right / left
#   G H I    platform that moves up or down / left or right / all four ways
#   J  hourglass: time bonus
#   K  cracked floor: falls away after it is stepped on
#   L  wall block
#   M N  red / green gate, opened with a key of its colour
#   O P  red / green key
#   Q  teleport (use none or two)
#   R  start position (exactly one per level)
#   S  exit
#   a  outside: the black area around the level (platforms cross it too)
#   b c d / e f g / h i j   the large rock, three by three tiles
#   k l m   stages of a falling floor; the game writes these itself
