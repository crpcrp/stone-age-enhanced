# Stone Age texts. Each [section] fills a fixed area of the program's data in
# the original's own encoding. A shorter text is padded with zero bytes; a
# longer one is refused.
#
# Text sections hold the bytes as written, except \r (carriage return: the
# next line down), \n (line feed: back to the left edge), \0 (end of a
# string), \\ (a backslash) and \xNN (any other byte; [ is always \x5b).
# Line breaks in this file are ignored: one follows each \0 and each line end.
# Characters are code page 437; in the font of the score and credits screens
# \xe0 starts bold letters and \xe2 ends them.
#   credits_idle     The credits (C on the menu): lines of 20 characters ended
#                    by \r\n\0. The scroll ends when its top line reaches byte
#                    2722; the lines after that are the last screen. Before it
#                    starts, the 20 bytes from 2177 and from 880 go to 694 and
#                    717, in an order left to chance.
#   credits_victory  The credits after level 100; the scroll ends at byte 1748.
#   jukebox          Song titles F1-F8 (one line each, ended by \r), the prompt
#                    and the key help, each ended by \0. Letters: A-Z . , " -
#                    space ! ? ( ' : ; 0-9.
#   song_files       Eight song file names of 13 bytes each, padded with \0.
#   scores           The heading of the score table; then the table itself,
#                    shown when there is no STONEAGE.HI: nine rows of 32 bytes
#                    (name from byte 2, score from byte 24, then \r\n) and \0.
#   name_entry       The text above the name being entered.
#
# Page sections are drawn with the letters of sprites 134-180: one line a
# record, x y |letters|, and an empty line ends a page. The letters are A-Z,
# 0-9, # $ ? ! % . : , ] [ and space; # $ % are ornaments, ] [ and space are
# blank. \xNN is any other sprite code. The game writes into fixed bytes:
#   retry_page                After a lost life.
#   completed_page            After a level: score glyphs at byte 16, the next
#                             level at 40. The 15 bytes from 45 are copied from
#                             60 (lives) or 75 (one life), the digit to 49. The
#                             password page is at 89, its letters at 93.
#   quotes                    Four pages; one is drawn on the completed page.
#   game_over_and_level_page  The game over page, then the page before a level
#                             with the level number at byte 122.
